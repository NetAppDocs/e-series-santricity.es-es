= Cambiar el orden de visualización de los estantes en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puede cambiar el orden de las bandejas que se muestran en la página hardware para que coincidan con el orden físico de las bandejas de un armario.

.Pasos
. En el panel izquierdo, selecciona menú:Hardware[Controllers and components].
. Selecciona la lista desplegable de un estante y luego selecciona *Cambiar orden* para reorganizar el orden de los estantes que se muestran en la página Hardware.
