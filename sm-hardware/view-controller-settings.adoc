= Ver la configuración del controlador en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible ver información sobre una controladora, como el estado de las interfaces del host, de las interfaces de la unidad y de los puertos de gestión.

.Pasos
. En el panel izquierdo, selecciona menú:Hardware[Controllers and components].
. Realice alguna de las siguientes acciones para ver la configuración de la controladora:
+
** Haga clic en el controlador para mostrar el menú contextual y, a continuación, seleccione *Ver configuración*.
** Seleccione el icono del controlador (junto a la lista desplegable *Bandeja*). Para configuraciones dúplex, seleccione *controladora A* o *controladora B* en el cuadro de diálogo y, a continuación, haga clic en *Siguiente*.
+
Se abre el menú deslizante de configuración del controlador.



. Revisa las secciones para desplazarte entre los ajustes de las propiedades del controlador.
+
.Detalles del campo
[%collapsible]
====
[cols="25h,~"]
|===
| Sección | Descripción 


 a| 
Detalles
 a| 
Muestra el estado del controlador, la fecha y hora, el nombre del modelo y el número de pieza de repuesto.



 a| 
Configuración actual
 a| 
Muestra la versión actual del firmware y la versión de NVRAM.



 a| 
Caché de datos
 a| 
Muestra los totales de la caché de datos.



 a| 
Módulos de caché de datos
 a| 
Muestra la ubicación, el estado y la capacidad del módulo de caché.



 a| 
Caché del procesador
 a| 
Muestra los totales de la caché del procesador.



 a| 
Dispositivos de copia de seguridad de caché
 a| 
Muestra la ubicación, el estado y la capacidad del dispositivo de copia de seguridad de la caché.



 a| 
Interfaces del host
 a| 
Muestra la información de la interfaz del host y el estado de enlace de cada puerto.



 a| 
Interfaces de unidad
 a| 
Muestra la información de la interfaz de la unidad y el estado de enlace de cada puerto.



 a| 
Configuración de los puertos de gestión
 a| 
Muestra los detalles del puerto de gestión, incluyendo el nombre de host del controlador, el inicio de sesión remoto y la configuración de red IP.



 a| 
Configuración del sistema de nombres de dominio (servidor DNS)
 a| 
Muestra la configuración de DNS, el servidor DNS principal y el servidor DNS de respaldo.



 a| 
Configuración del servidor NTP (network time protocol)
 a| 
Muestra los detalles de configuración del servicio NTP y del servidor NTP.

|===
====
. Haga clic en *Cerrar*.
