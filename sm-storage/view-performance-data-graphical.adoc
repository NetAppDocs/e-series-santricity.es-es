= Ver datos gráficos de rendimiento en SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es posible ver datos gráficos de rendimiento para objetos lógicos, objetos físicos, aplicaciones y cargas de trabajo.

.Acerca de esta tarea
Los gráficos de rendimiento muestran datos históricos, así como datos en directo que se capturan en el momento. Una línea vertical sobre el gráfico, con la etiqueta actualización en vivo, distingue entre datos históricos y datos en directo.

*Vista de panel*

El panel de control contiene un gráfico que muestra el rendimiento a nivel de la matriz de almacenamiento. Puedes seleccionar una serie limitada de métricas desde esta vista o hacer clic en *Ver detalles de rendimiento* para ir al menú:Monitoring[Performance] y seleccionar todas las métricas disponibles.

*Vista detallada*

Los gráficos disponibles en la página Rendimiento se basan en tus selecciones:

* *Tipos de objetos* -- selecciona las categorías de objetos que se van a incluir (por ejemplo, matrices de almacenamiento, controladores, pools y grupos de volúmenes, aplicaciones, cargas de trabajo, volúmenes, canales y unidades).
* *Objetos* -- permite seleccionar hasta cinco objetos concretos de entre los tipos de objetos seleccionados.


.Pasos
. Selecciona el menú: Supervisión [Rendimiento].
. Utiliza *Tipos de objeto* y *Objetos* para seleccionar los datos que deseas mostrar. Puedes seleccionar hasta cinco objetos; utiliza el campo de búsqueda en la lista *Objetos* para buscar nombres de objetos o partes de nombres.
+
No todas las métricas están disponibles para todos los tipos de objetos. Las matrices de almacenamiento y los controladores no informan sobre la latencia, solo los controladores informan sobre la utilización de CPU, y solo los controladores y los canales informan sobre el headroom.

. Utiliza *Intervalo de tiempo* para seleccionar el periodo que quieres mostrar.
. Haz clic en *Actualizar*.
. *Opcional:* En un gráfico individual, usa *Comparar* para superponer otro tipo de métrica para los mismos objetos.
. Según sea necesario, use las opciones adicionales para ver datos de rendimiento.
+
.Opciones adicionales
[%collapsible]
====
[cols="25h,~"]
|===
| Opción | Descripción 


 a| 
Intervalo de tiempo
 a| 
Seleccione la cantidad de tiempo que desea ver (5 minutos, 1 hora, 8 horas, 1 día, 7 días, o 30 días). El valor predeterminado es 1 hora.


NOTE: La carga de los datos de rendimiento correspondientes a un periodo de 30 días puede tardar varios minutos. No salgas de la página web, no la actualices ni cierres el navegador mientras se cargan los datos.



 a| 
Detalles de punto de datos
 a| 
Pase el cursor sobre el gráfico para ver métricas de un punto de datos en particular.



 a| 
Barra de desplazamiento
 a| 
Use la barra de desplazamiento debajo del gráfico para ver un plazo anterior o posterior.



 a| 
Barra de zoom
 a| 
Debajo del gráfico, arrastre los bordes de la barra de zoom para reducir un plazo. Cuanto más ancha sea la barra de zoom, menos granulares serán los detalles del gráfico.

Para restablecer el gráfico, seleccione una de las opciones del plazo.



 a| 
Arrastre y suelte
 a| 
En el gráfico, arrastre el cursor de un momento específico a otro para expandir un plazo.

Para restablecer el gráfico, seleccione una de las opciones del plazo.
