== Novedades en la versión 12.10R1

[[new-features-in-version-12-10]]
== Novedades en la versión 12.10

[cols="35h,~"]
|===
| Nueva función | Descripción 


 a| 
Compatibilidad con la ampliación SAS para los sistemas de almacenamiento EF50 y EF80
 a| 
Los sistemas de almacenamiento EF50 y EF80 ahora admiten la ampliación SAS, lo que permite aumentar la capacidad de almacenamiento y la flexibilidad. Con la expansión SAS, puedes conectar cajas de almacenamiento adicionales a los sistemas EF50 y EF80, lo que te permite ampliar tu entorno de almacenamiento según lo necesites. Esta función es especialmente beneficiosa para las organizaciones que requieren soluciones de almacenamiento de gran capacidad y quieren maximizar su inversión en las plataformas EF50 y EF80.



 a| 
Compatibilidad con NVMe sobre TCP para los sistemas de almacenamiento E-Series
 a| 
Los sistemas de almacenamiento E-Series ahora son compatibles con NVMe sobre TCP, lo que ofrece una opción adicional de interfaz del host para un acceso al almacenamiento de alto rendimiento. NVMe sobre TCP permite una comunicación eficiente y de baja latencia entre el sistema de almacenamiento y los hosts conectados, aprovechando las ventajas del protocolo NVMe en redes TCP/IP estándar. Esta compatibilidad mejora la versatilidad de los sistemas E-Series, lo que permite a las organizaciones implementarlos en entornos en los que se prefiere o se requiere NVMe sobre TCP.



 a| 
Mejoras en la interfaz de usuario de SANtricity System Manager
 a| 
La interfaz de usuario de SANtricity System Manager ha incorporado nuevas mejoras para optimizar la navegación, la facilidad de uso y la experiencia general del usuario. Entre estas mejoras se incluyen una disposición y organización actualizadas de las tareas de gestión, así como flujos de trabajo más intuitivos para las operaciones habituales de gestión del almacenamiento.



 a| 
Compatibilidad ampliada de la plataforma E-Series para la nueva interfaz de usuario de SANtricity System Manager
 a| 
La nueva interfaz de usuario de SANtricity System Manager, que se presentó en la versión SANtricity 12.00 para los sistemas de almacenamiento EF80 y EF50, se ha ampliado para dar soporte a otras plataformas de almacenamiento E-Series. Esto significa que los usuarios que gestionan una gama más amplia de sistemas de almacenamiento E-Series ahora pueden beneficiarse de la interfaz modernizada y de las funciones de usabilidad mejoradas. La compatibilidad ampliada incluye el soporte para determinados modelos de sistemas de almacenamiento E-Series, lo que permite a los usuarios aprovechar la navegación mejorada y las tareas de gestión optimizadas en una mayor parte de su infraestructura de almacenamiento.



 a| 
Compatibilidad con unidades de rendimiento y capacidad mixtos para los sistemas EF80 y EF50
 a| 
Los sistemas de almacenamiento EF80 y EF50 ahora admiten unidades SSD NVMe de alto rendimiento y de gran capacidad en la misma matriz de almacenamiento, siempre que se respete el número mínimo de unidades (6 para alto rendimiento, 12 para gran capacidad). Las unidades de alto rendimiento y de gran capacidad deben permanecer en pools y grupos de volúmenes separados.



 a| 
Aumento del límite de caracteres para los nombres de volúmenes estándar y thin
 a| 
El límite de caracteres para los nombres de volúmenes estándar y thin se ha aumentado de 30 a 60 caracteres.


NOTE: No se admite la actualización a una versión anterior a la 11.90 del software SANtricity OS si existen volúmenes estándar o thin cuyos nombres superen los 30 caracteres. Si planeas realizar una actualización a una versión anterior del software SANtricity OS (versión 11.90 o anterior), cambia los nombres de cualquier volumen estándar o thin cuyos nombres superen los 30 caracteres antes de realizar la actualización.



 a| 
El tiempo de espera mínimo por inactividad de la interfaz de usuario de SANtricity System Manager ahora es de 10 minutos
 a| 
El tiempo de espera por inactividad de la interfaz de usuario de SANtricity System Manager se ha actualizado a un mínimo de 10 minutos. Anteriormente, el tiempo de espera mínimo por inactividad era de 15 minutos. Este cambio ayuda a mejorar la seguridad al asegurar que la interfaz de usuario cierre la sesión automáticamente después de 10 minutos de inactividad.

|===

[[new-features-in-version-12-0]]
== Novedades en la versión 12.0


NOTE: La versión 12.0 de SANtricity OS solo es compatible con los nuevos sistemas de almacenamiento all-flash EF80 y EF50. Si estás usando SANtricity OS 11.9 o anterior, consulta link:known-issues.html["Problemas conocidos"] para ver una lista de las nuevas funciones en versiones anteriores.

[cols="35h,~"]
|===
| Nueva función | Descripción 


 a| 
Nuevos modelos de sistemas de almacenamiento – sistemas de almacenamiento all-flash EF80 y EF50
 a| 
Esta versión presenta los sistemas de almacenamiento all-NVMe-flash EF80 y EF50. El EF80 y el EF50 admiten 24 unidades SSD NVME y una tarjeta de duplicación entre controladores por controlador. Las interfaces de host NVMe over Fabrics admitidas incluyen NVMe over RoCE, NVMe over IB, NVMe over FC para EF80 y NVMe over FC para EF50. La interfaz SCSI admitida es Fibre Channel para ambos sistemas. El EF50 admite hasta dos tarjetas de interfaz del host por controlador, mientras que el EF80 admite hasta tres tarjetas de interfaz del host por controlador.

Las unidades SSD NVMe de gran capacidad de 30TB o 60TB también son compatibles con EF80 y EF50. EF80 y EF50 solo pueden utilizar Dynamic Disk Pool cuando la matriz está equipada con unidades de 30TB o 60TB.



 a| 
Nueva interfaz de usuario para SANtricity System Manager
 a| 
Para los nuevos controladores EF80 y EF50, la interfaz de usuario de SANtricity System Manager se ha rediseñado para ofrecer un aspecto y una experiencia más modernos. La nueva interfaz incluye una navegación por el panel izquierdo y una mayor facilidad de uso para agilizar las tareas de administración.


NOTE: La nueva interfaz de usuario está disponible actualmente solo para los sistemas de almacenamiento EF80 y EF50 con la versión SANtricity 12.00. Si estás usando SANtricity 11.9 o una versión anterior, consulta link:https://docs.netapp.com/us-en/e-series-santricity-119/system-manager/index.html["System Manager 11,9 de SANtricity"] para instrucciones sobre cómo usar la interfaz de usuario heredada.



 a| 
Subject Alternative Names (SANs) para el certificado de servidor ahora solo permiten letras, dígitos y guiones
 a| 
Al crear o editar un certificado de servidor en SANtricity System Manager o Unified Manager, el campo Subject Alternative Names (SANs) ahora solo permite letras, dígitos y guiones. Este cambio mejora la seguridad y garantiza la compatibilidad con los estándares del sector para certificados SSL/TLS.



 a| 
El tamaño de segmento de Dynamic Disk Pools ahora es de 32K por defecto para SSD y sistemas basados en NVMe
 a| 
Para los Dynamic Disk Pools en sistemas basados en SSD y NVMe, el tamaño de segmento predeterminado se ha cambiado a 32K. Antes, el tamaño de segmento predeterminado de los Dynamic Disk Pools estaba fijado en 128K para estos sistemas. Este cambio optimiza el rendimiento para cargas de trabajo que implican una mezcla de operaciones de E/S pequeñas y grandes.



 a| 
El editor de scripts ya está disponible en SANtricity System Manager
 a| 
Ahora tienes disponible un nuevo editor de secuencias de comandos dentro de SANtricity System Manager. El editor de secuencias de comandos te permite crear o editar un archivo de secuencia de comandos, guardar un archivo de secuencia de comandos en el disco local de la estación de gestión de almacenamiento o cargar un archivo de secuencia de comandos desde el disco. El editor de secuencias de comandos ofrece comprobación de sintaxis y capacidades de ejecución de comandos para gestionar tu sistema de almacenamiento. Para obtener más información, consulta link:sm-support/use-script-editor.html["Utiliza el editor de scripts en SANtricity System Manager"^].

|===
